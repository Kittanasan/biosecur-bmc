# ระบบบันทึกข้อมูลการเลี้ยงกุ้งตามระบบ Biosecurity

ศูนย์วิจัยและพัฒนาการเพาะเลี้ยงสัตว์น้ำชายฝั่งฉะเชิงเทรา

เว็บแอปไฟล์เดียว ทำงานออฟไลน์ได้ ข้อมูลถูกเก็บไว้ในเครื่องของผู้ใช้ (localStorage)
ไม่ต้องติดตั้งเซิร์ฟเวอร์ ไม่ต้องมีอินเทอร์เน็ตหลังโหลดหน้าเว็บครั้งแรก

## ใช้งานออนไลน์ (ทุกแพลตฟอร์ม)

เปิดจาก GitHub Pages แล้วใช้งานได้ทันที ทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## เมนูที่มี

**ข้อมูลการเลี้ยงและสุขภาพ**
1. ควบคุมการเข้าออกบุคลากร / ผู้เยี่ยมชมฟาร์ม
2. การให้อาหารและอุณหภูมิน้ำ (08.30 / 12.00 / 16.00 / 20.00 และ 08.30 / 15.00)
3. สุขภาพสัตว์น้ำ (ลำไส้ / ขาว่ายน้ำ / ตัวตาย ที่ 08.30 และ 16.00)
4. คุณภาพน้ำ (แอมโมเนีย ไนไตรท์ DO pH แม็กนีเซียม แคลเซียม ความเค็ม)

**วัสดุ-สารเคมีที่ใช้ในฟาร์ม**
5. วัสดุที่ใช้ในการเตรียมน้ำ
6. วัสดุที่ใช้ในการเตรียมอ่างย่ำเท้า
7. วัสดุที่ใช้ในการล้างอุปกรณ์

**น้ำใช้และการเคลื่อนย้ายสัตว์น้ำ**
8. แหล่งน้ำใช้
9. การเคลื่อนย้ายสัตว์น้ำ

**รายงานผล**
- สร้างไฟล์ Word (.docx), PDF, Excel (.xlsx), PowerPoint (.pptx) และ JSON
- นำเข้าข้อมูลกลับจากไฟล์ JSON

## รองรับแพลตฟอร์ม

| แพลตฟอร์ม | เบราว์เซอร์ |
|---|---|
| Windows / macOS / Linux / ChromeOS | Chrome, Edge, Firefox, Safari, Opera |
| Android | Chrome, Samsung Internet, Firefox |
| iPhone / iPad | Safari (มีแชร์ไฟล์เพื่อบันทึกลงแอป Files) |

- เบราว์เซอร์รุ่นเก่าที่ไม่รู้จักช่องกรอกวันที่ จะสลับเป็นช่องกรอกวันที่แบบ พ.ศ. อัตโนมัติ
- ถ้าปิดการเก็บข้อมูล (โหมดส่วนตัว) ระบบจะเตือนและให้ส่งออก JSON เก็บไว้

## ไฟล์

- `index.html` — หน้าจอ (แบบฟอร์ม ตาราง แผงรายงาน)
- `js/app.js` — ตรรกะของหน้าจอ: บันทึก/แก้ไข/ลบ ตัวกรอง รายชื่อผู้บันทึก นำเข้า-ส่งออก
  นิยามของทั้ง 9 หมวดอยู่ในตัวแปร `MOD` ที่เดียว
- `js/report.js` — ตัวสร้างไฟล์ Word / Excel / PowerPoint / PDF-Print / JSON

## จัดการรายชื่อผู้บันทึก

กดปุ่ม "รายชื่อผู้บันทึก" ที่หน้าแรก เพื่อเพิ่ม แก้ชื่อ เรียงลำดับ หรือลบรายชื่อ
รายชื่อจะแสดงในช่อง "ผู้บันทึกข้อมูล" ของทุกฟอร์ม และถูกรวมไปในไฟล์ JSON ที่ส่งออก

## หมายเหตุ

ข้อมูลเก็บในเบราว์เซอร์ของอุปกรณ์แต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง
ถ้าต้องย้ายเครื่อง ให้ส่งออก JSON แล้วนำเข้าในเครื่องใหม่
